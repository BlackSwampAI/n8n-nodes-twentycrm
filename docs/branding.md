# Branding and Twenty icon provenance

The action and trigger icons use the unmodified official Twenty 96×96 SVG from the Twenty-controlled `twentyhq/twenty` repository, reconfirmed at immutable commit `ee6a5c37cd9dc420934c02cf32256234f7e96d01`, accessed 2026-09-06:

`https://raw.githubusercontent.com/twentyhq/twenty/ee6a5c37cd9dc420934c02cf32256234f7e96d01/packages/twenty-codex-plugin/assets/twenty-logo.svg`

SHA-256: `0016254102d200b1598b4c1ecb88dfa398ec3a34db0616ed9441eda887ff2fef`.

The same byte-for-byte square asset is used for light and dark references. Release and package checks pin both source and packaged hashes. On 2026-09-06, the current official Twenty repository README was also checked and referenced `packages/twenty-website/public/images/core/logo.svg`. Byte/hash or visual equivalence between that current website asset and the packaged codex-plugin asset was not established in this migration, so current-brand equivalence remains unverified. The icon is unchanged pending a deliberate upstream comparison; do not redraw or approximate it.
