# Twenty CRM API and operation matrix

Twenty generates record APIs from each workspace schema rather than publishing one static record OpenAPI contract. This matrix therefore separates the current public documentation, the pinned self-hosted Twenty v2.9.0 behavior exercised by this repository, and behavior that still needs current-version live verification. Workspace-specific API documentation remains authoritative for names, fields, and permissions.

| Resource family    | Advertised operations                          | Public contract                                                      | Pinned v2.9 evidence                                                                             | Current-version status                                                                                                                                                                                                          |
| ------------------ | ---------------------------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Company            | Create, Get, Get Many, Update, Delete          | Core REST `/rest/companies`; workspace-generated fields              | Full exact-owned lifecycle and absence cleanup                                                   | Fixed route is not live-qualified on current Twenty                                                                                                                                                                             |
| Person             | Create, Get, Get Many, Update, Delete          | Core REST `/rest/people`; workspace-generated fields                 | Reads plus exact-owned lifecycle coverage                                                        | Fixed route is not live-qualified on current Twenty                                                                                                                                                                             |
| Opportunity        | Create, Get, Get Many, Update, Delete          | Core REST `/rest/opportunities`; workspace-generated fields          | Full exact-owned lifecycle and cleanup                                                           | Fixed route is not live-qualified on current Twenty                                                                                                                                                                             |
| Task               | Create, Get, Get Many, Update, Delete          | Core REST `/rest/tasks`; workspace-generated fields                  | Full exact-owned lifecycle and cleanup                                                           | Fixed route is not live-qualified on current Twenty                                                                                                                                                                             |
| Note               | Create, Get, Get Many, Update, Delete          | Core REST `/rest/notes`; workspace-generated fields                  | Full exact-owned lifecycle and cleanup                                                           | Fixed route is not live-qualified on current Twenty                                                                                                                                                                             |
| Record             | Create, Get, Get Many, Update, Delete          | Core REST `/rest/{workspace_plural_name}`                            | Custom object/field creation, metadata rediscovery, CRUD, pagination, and exact cleanup          | Modern metadata shapes have fixture tests; current record mutations remain unverified                                                                                                                                           |
| Schema Object      | Get, Get Many                                  | Metadata GraphQL `/metadata`; workspace object connection            | Paginated discovery and normalization                                                            | Supports fixture-tested legacy v2.9 and modern v2.35 flag shapes                                                                                                                                                                |
| Twenty CRM Trigger | Record Created, Record Updated, Record Deleted | User-managed outbound webhook; HMAC-SHA256 over `timestamp:raw body` | Native signed delivery and the `eventName`/`objectMetadata.nameSingular` envelope were exercised | Current sender source at `ee6a5c37…` retains `eventName`, `objectMetadata`, `workspaceId`, `webhookId`, `eventDate`, and `record`; the public docs' `event`/`data`/`timestamp` example does not match the sender implementation |

Get Many record operations use cursor pagination, Return All/Limit, and optional raw REST filter/order expressions. Create and Update offer metadata-driven field mapping or JSON input. Record mutation retries are disabled. Schema mutation and automatic webhook registration are not exposed.

## Evidence boundaries

- Current human contract: [Twenty APIs](https://docs.twenty.com/developers/extend/api) and [Twenty webhooks](https://docs.twenty.com/developers/extend/webhooks).
- Current sender evidence: [`call-webhook.job.ts`](https://github.com/twentyhq/twenty/blob/ee6a5c37cd9dc420934c02cf32256234f7e96d01/packages/twenty-server/src/engine/metadata-modules/webhook/jobs/call-webhook.job.ts), [`webhook-job-data.type.ts`](https://github.com/twentyhq/twenty/blob/ee6a5c37cd9dc420934c02cf32256234f7e96d01/packages/twenty-server/src/engine/metadata-modules/webhook/types/webhook-job-data.type.ts), and [`transform-event-batch-to-webhook-events.ts`](https://github.com/twentyhq/twenty/blob/ee6a5c37cd9dc420934c02cf32256234f7e96d01/packages/twenty-server/src/engine/metadata-modules/webhook/utils/transform-event-batch-to-webhook-events.ts), accessed 2026-09-06.
- Pinned runtime: `twentycrm/twenty:v2.9.0@sha256:0afdba1494ea50bad6eb278a20ae35933317483f23501157c2ed866b74d4bc4a`; see `docs/LOCAL_TWENTY.md`.
- Modern compatibility fixtures cover the v2.35 metadata flag shape but are not a substitute for a current disposable live stack.
- Twenty Cloud and broad Twenty/n8n version compatibility are not claimed.
